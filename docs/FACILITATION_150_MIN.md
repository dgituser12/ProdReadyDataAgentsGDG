# GDG Essex — 165-minute facilitation plan

| Time | Duration | Activity |
|---|---:|---|
| 0–5 | 5 min | Welcome, outcomes and Colab readiness check |
| 5–25 | 20 min | Opening talk: Data Agent architecture, ten concepts, business scenario and safety boundaries |
| 25–55 | 30 min | Notebook 1 — Build Your First Enterprise Data Agent: agent foundations and semantic metric interpretation |
| 55–100 | 45 min | Notebook 2 — Give Your Agent Enterprise Expertise: Data Harness, data quality/freshness, governed tools and query safety |
| 100–105 | 5 min | Break |
| 105–150 | 45 min | Notebook 3 — Build the Multi-Agent System: orchestration, evidence-backed answers and data-aware evaluation |
| 150–160 | 10 min | Discussion, optional integrations and Q&A |
| 160–165 | 5 min | Recap, next steps and close |

**Total: 165 minutes.** Notebook 0 is completed before the event; Notebook 4 is post-workshop reference material. Optional integrations remain disabled by default and are not required to complete the core labs.
